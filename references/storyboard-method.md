# Storyboard Method Reference

本文件是 `SKILL.md` 的导演/拆镜细则。目标不是追求术语数量，而是让剧本经过拆解后具备 **可拍、可剪、可生成、可追溯、可修复** 五个属性。

## 1. 从剧本建立 Scene Ledger

每个 Scene 先抽取：

- `scene_id`
- 内/外景、地点、时间
- 出场人物
- 进入场景时人物位置和状态
- 关键道具及初始状态
- 这场戏的目标、阻力、结果
- 新增/改变的信息
- 出口状态（谁在哪、拿着什么、知道什么、下一场承接什么）

如果原稿没有明确场号，自建稳定 ID，但不要更改原文顺序。

## 2. Narrative Beat 的判断标准

Beat 不是一句话；Beat 是一次“状态发生了有意义变化”。

优先在这些地方切 Beat：

1. **目标变化**：人物开始想得到/阻止新的东西。
2. **信息变化**：人物或观众获得关键事实。
3. **权力变化**：谁占上风发生变化。
4. **物理状态变化**：门打开、枪被夺走、合同被撕、人物倒地。
5. **情绪阈值变化**：平静 → 怀疑、克制 → 爆发，但必须能从动作/表演观察到。
6. **问题变化**：一个悬念被提出、延期、兑现或替换。

每个 Beat 建议包含：

```json
{
  "id": "E01-S02-B03",
  "source": "原剧本对应句/范围",
  "event": "阿丽娅发现徽章背面的家族刻印",
  "type": "information",
  "characters": ["C01"],
  "props": ["P03"],
  "dialogue": null
}
```

## 3. Beat → Shot 的决策

先问：**观众为了理解这个 Beat，必须看到什么？**

再问：

- 需要看到动作过程，还是只需要结果？
- 需要看说话人，还是听者反应更重要？
- 关键证据是否小到必须 insert/ECU？
- 空间关系是否首次建立？
- 动作/视线是否需要连续剪辑？
- 一个镜头是否已经承担两个互相竞争的注意力中心？

如果“必须看到”的信息彼此需要不同机位/不同景别/不同注意力中心，就拆镜。

## 4. 原子镜头判定

### 4.1 正常原子镜头

一个镜头最好可以写成一句明确动作：

> 近景固定：阿丽娅低头翻过徽章，在背面刻印出现时手指停住。

它有：主体、动作、结果、单一景别、单一主要摄影意图。

### 4.2 过载镜头

下面这种通常应该拆：

> 全景跟拍她跑进大厅，镜头绕到正面推近，她看到父亲后停住，再切徽章特写，父亲说话，她回头落泪。

这里至少包含：进入、环绕、推近、发现、insert、对白、反应、隐藏剪辑。

## 5. Coverage 设计

Coverage 不是“多拍一点保险”，而是确保剪辑有足够信息和节奏选择。

### 5.1 对话 Coverage

可选组件：

- master / two-shot：空间与关系；
- OTS A / OTS B：双方关系和轴线；
- single medium / close：角色信息与情绪；
- reaction：重台词后的听者；
- insert：手机、文件、伤口、戒指、钥匙、武器、屏幕。

什么时候需要切：

- 说话权发生转移；
- 一句话改变了关系；
- 听者反应比说话者更有戏；
- 关键证据必须读清；
- 保持单镜会让信息密度或口型负载过高。

不要“每人一句就切一次”机械正反打。

### 5.2 动作 Coverage

动作拆成相位：

```text
准备 → 接近 → 接触 → 施力/执行 → 结果 → 反应/恢复
```

只需要选择剧情必须读清的相位，不必每阶段都拍。

典型连续剪辑：

```text
Shot A：手伸向门把（动作进行中切）
Shot B：近景手握住并下压门把
Shot C：门开，人物跨入新空间
```

## 6. 景别语义

不要把景别当装饰。

| 景别 | 常见任务 |
|---|---|
| Extreme Wide / Establishing | 世界、尺度、地理关系 |
| Wide / Full | 人物身体、多人站位、动作路线 |
| Medium Wide / Cowboy | 人物与手部/道具兼顾 |
| Medium | 对话、普通动作、人物关系 |
| Medium Close | 高信息量对白、情绪增强 |
| Close-Up | 决定、反应、关键信息 |
| Extreme Close-Up / Insert | 证据、细节、冲击点 |

连续多个镜头都使用相同景别时，检查是否真的需要切；如果只是换一句台词，可能没有新增视觉价值。

## 7. Camera Angle 的叙事用途

- Eye level：中性、关系清楚。
- High angle：弱势、暴露、空间信息。
- Low angle：压迫、权力、规模。
- OTS：人物关系、对话方向。
- POV：角色主观信息；必须知道 POV 属于谁。
- Overhead：空间布局、仪式、群体关系。
- Dutch angle：失衡；慎用，不能成为“紧张”的默认按钮。

角度变化应该对应信息或权力变化，而不是随机炫技。

## 8. Camera Movement

### Static

默认优先。对 AI 生成尤其稳定。人物动作已经足够时，不必再让摄影机做复杂运动。

### Push / Dolly In

用于发现、情绪逼近、压力增加。最好有明确目标，例如推向手中的戒指，而不是“缓慢推进增加电影感”。

### Pull Out / Dolly Out

用于揭示后果、孤立人物、收束。

### Pan / Truck

用于跟随注意力、揭示旁侧信息、保持空间连续。

### Tracking

用于主体持续位移。明确相对位置：跟在后方、侧向平行、正向后退等。

### Arc

用于关系/权力变化或空间揭示。AI 场景里风险较高，避免同时加入复杂人物互动。

## 9. Blocking 优先于 Camera

先解决人物和物体“在哪里、往哪走、看哪里”，再选机位。

每镜最少知道：

- 主体起始位置；
- 主体朝向；
- 视线目标；
- 移动路径；
- 道具在哪只手；
- 镜头结束时位置。

两人对话示例：

```text
C01：画面左，面向右
C02：画面右，面向左
Axis：两人连线
```

如果机位跨过轴线，必须有理由和视觉过渡，例如摄影机实际越轴、角色换位或先用中性轴镜头重新建立。

## 10. 180°轴线与屏幕方向

空间连续的最低要求：观众知道谁在左、谁在右、谁朝哪里走。

质量检查：

- 相邻正反打是否保持视线方向相反且合理？
- 人物上一镜向画面右跑，下一镜是否突然无理由向左？
- 道具从右手无过渡跳到左手了吗？
- POV/OTS 是否让观众误认人物位置？

违反 180°规则不是绝对错误，但**无意违反**通常会造成混乱。

## 11. Match Rules

### Match on Action

在动作中间切，前后共享同一动作相位。

### Eyeline Match

人物看向画外目标 → 下一镜给该目标，方向和高度合理。

### Graphic / Shape Match

形状、构图或视觉重心相似的镜头可作为有意转场，但要标记为编辑设计，不要与物理连续混淆。

### Sound Bridge

J-cut / L-cut 可以跨镜延续声音。分镜表要写清声音起止，不要只写“转场自然”。

## 12. Start / End State 合同

每镜写可检查的首尾状态。

不合格：

```text
start_state: 紧张地站着
end_state: 更加紧张
```

合格：

```text
start_state:
- C01 站画面右前景，右手垂下，短剑仍在鞘内
- C02 在左后景，面对 C01

end_state:
- C01 右手已握住剑柄，身体左转约 30°，视线锁定 C02
- C02 后撤半步，仍在画面左侧
```

下一镜如果从“剑已经拔出”开始，就必须有拔剑动作发生在上一镜、镜间省略被明确接受，或中间补镜。

## 13. Continuity Ledger

逐镜追踪以下状态：

### Character

- 位置：left/center/right + foreground/midground/background
- 朝向：面向哪边/哪个角色
- 姿势：站/坐/跪/倒地
- 动作阶段
- 服装和配件
- 发型、污渍、伤势
- 已知信息（只在剧情连续性需要时记录）

### Prop

- 位置
- 持有者
- 持有手
- 开/关、完整/损坏、空/满等状态

### Environment

- 时间
- 天气
- 灯光开关和色温状态
- 门窗状态
- 大型移动物体位置

### Audio

- 当前环境底噪
- 正在延续的对白/VO
- 音乐是否进入/退出
- J/L cut

## 14. 抽象 → 可见/可听

### 心理

原文：

> 他终于意识到自己被骗了。

可视化选项：

- 目光从转账记录移到对方头像；
- 再次点开已拉黑提示；
- 手指停住；
- 手机从耳边缓慢放下。

### 权力变化

原文：

> 她重新掌握主动。

可视化：

- 她把签好的合同翻到最后一页，推到对方面前；
- 对方伸出的手停住；
- 她坐下，对方仍站着。

### 氛围

原文：

> 气氛压抑。

不要直接复制。寻找剧本允许的证据：长停顿、距离、遮挡、局促空间、低声、门锁声、无人回应等。

## 15. 镜头节奏

节奏不是“全部 3 秒”。

检查整个序列是否出现：

- 景别长时间不变；
- 每镜时长完全相同；
- 每句台词都切；
- 关键反转和普通信息拥有同样视觉重量；
- 高潮前没有压缩，高潮后没有落点。

典型短剧节奏可以更密，但仍应由信息密度驱动。

## 16. 开场钩子

钩子必须来自剧情，而不是自动新增“爆炸/打脸/生死危机”。

优先寻找原剧本中已有的：

- 未完成动作；
- 异常物；
- 身份冲突；
- 证据；
- 倒计时；
- 不合常理的关系；
- 强烈结果先展示再解释。

钩子必须在后文兑现、延期或明确转化。

## 17. AI 视频可执行性风险

以下组合会显著提高生成风险：

- 3 人以上同步精确互动；
- 两个以上关键手部/小道具交互；
- 多人同时说长对白；
- 快速位移 + 复杂环绕摄影 + 精确道具操作；
- 一个镜头内换地点/服装/时间；
- 需要精确可读长文字；
- 需要完全稳定品牌 Logo/包装文字却没有强参考。

降级顺序：

1. 固定机位；
2. 减少同时动作主体；
3. 把精细手部动作拆成 insert；
4. 将对白与复杂动作分开；
5. 拆镜；
6. 将声音后期处理；
7. 必要时改真人/混合制作。

## 18. 审查顺序

不要一上来只看“镜头好不好看”。按责任层检查：

1. 剧情 Beat 是否正确；
2. Scene/时空是否正确；
3. Blocking 是否连续；
4. Shot 是否原子、可执行；
5. Coverage 是否足够；
6. 时长与对白是否合理；
7. Camera 是否服务剧情；
8. Start/End state 是否可承接；
9. AI 任务是否过载（若适用）。

上游错误优先修，不要用下游 Prompt 去补救错误分镜。
