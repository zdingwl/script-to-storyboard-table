# Director Plan Reference

本文件定义在正式拆 Shot 之前必须完成的“导演预规划”。它解决的问题是：**剧本顺序正确，不代表镜头顺序自然；单镜漂亮，不代表连续播放成立。**

Director Plan 不是第二份剧本，也不是风格提案。它只记录会直接影响镜头结构的导演决策。

## 1. 何时建立

以下任一情况都应先做：

- 从剧本第一次生成分镜；
- 用户反馈“镜头之间接不上”“少镜头”“站位不对”“动作不连贯”；
- 同一 Scene 有多人互动、关键道具、动作冲突或明显权力变化；
- 要将多个 cuts 组合成一次 AI 视频生成任务；
- 原稿只有对白，没有明确 blocking；
- 翻译后镜头时长需要重排；
- 已有分镜需要整体节奏诊断。

如果用户提供了已批准 Director Plan，优先读取，不要擅自重做。

## 2. Scene Director Plan

每场最少记录：

```json
{
  "dramatic_job": "本场必须完成的叙事任务",
  "turn": "本场真正发生变化的点",
  "entry_state": "进入本场时的重要状态",
  "exit_state": "离开本场时的重要状态",
  "pov": "观众主要跟谁/保持什么观看位置",
  "information_control": "此刻给什么、暂时不给什么",
  "emotional_curve": "情绪如何从 A 发展到 B",
  "power_shift": "优势是否/何时转移",
  "visual_strategy": "本场主要视觉组织逻辑",
  "geography_plan": "关键空间锚点、入口、出口、障碍和关系",
  "blocking_plan": "人物起始关系、关键移动和结束关系",
  "axis_plan": "轴线如何建立/保持/有意越轴",
  "camera_strategy": "摄影机为什么这样组织",
  "lens_strategy": "wide/normal/telephoto 等叙事用途",
  "lighting_strategy": "光线如何服务信息和情绪",
  "editing_strategy": "节奏、切换密度、是否压缩/停留",
  "sound_strategy": "环境、对白、静音点、声桥",
  "transition_in": "如何承接上一场",
  "transition_out": "如何进入下一场",
  "coverage_obligations": [
    "观众必须看清的动作/证据/反应"
  ],
  "pacing": "held | neutral | compressed",
  "hook_role": "none | setup | escalation | end_hook"
}
```

其中 `lens_strategy` 先写叙事意图，不必在没有项目镜头体系时虚构具体焦段；`lighting_strategy` 应服从项目 Visual Bible，而不是每场重新发明 look。

## 3. dramatic_job

只写这一场**必须完成什么**，不要写剧情摘要。

不合格：

> 两个人在办公室吵架，气氛紧张。

合格：

> 让观众明确 C02 已掌握合同证据，并让 C01 从占上风转为被动。

它决定哪些镜头是必需的，哪些只是装饰。

## 4. turn

`turn` 是这场戏真正改变的地方。可能是：

- 新证据出现；
- 人物做出决定；
- 权力关系逆转；
- 目标被阻断；
- 身份暴露；
- 威胁从抽象变具体；
- 一个悬念被兑现，同时产生更大的问题。

如果一场戏找不到 turn，检查它是否只是过场，或是否可以与相邻场合并。不要为了满足模板凭空制造转折。

## 5. entry_state / exit_state

Scene 级别也需要首尾状态。

重点写：

- 人物位置与关系；
- 谁知道什么；
- 关键道具在哪；
- 伤势/服装/环境是否变化；
- 上一场留下的未完成动作；
- 下一场必须承接的事实。

这能防止“场内镜头都合理，但场与场之间跳掉一拍”。

## 6. visual_strategy

不要写抽象风格词。写镜头组织策略，例如：

- 先用双人关系镜建立左右位置，关键证据出现后转为单人近景；
- 先锁定受困者 POV，直到门打开才第一次给出外部空间；
- 前半段保持固定机位和长停顿，证据出现后提高切换密度；
- 全场围绕桌面道具建立 eyeline → insert → reaction 链。

`visual_strategy` 应能解释为什么某些镜头需要存在。

## 7. Blocking Plan

先定义人物，再定义机位。

至少回答：

- 每个人从哪里开始；
- 相互朝向；
- 主要视线目标；
- 哪个动作会改变距离/位置；
- 谁靠近、谁退让；
- 关键道具由谁持有、哪只手；
- Scene 结束时谁在哪。

示例：

```text
C01：画面左近桌边，面向右；右手持 P01。
C02：画面右靠门，面向左。
关键移动：C02 走到桌前夺走 P01；C01 后退半步。
结束关系：C02 占据画面中央，C01 落到右后景。
```

如果 blocking 不清楚，不要先设计复杂运镜。

## 8. Axis Plan

对话/对峙场景应建立轴线。

记录：

```text
Axis: C01 ↔ C02
Initial camera side: south side
Screen relation: C01 left / C02 right
Crossing policy: locked
```

允许有意越轴，但要写清理由和过渡：

- 摄影机实际移动穿越轴线；
- 角色交叉换位；
- 先用 neutral / head-on shot 重置空间；
- 明确制造迷失感，并且这是叙事目的。

无意识越轴不算“有风格”。

## 9. Coverage Obligations

Coverage 不是越多越好，而是**剪辑必须拥有的证据**。

每个 obligation 应属于以下一种：

### Space

- 第一次看清人物与出口的位置；
- 需要知道谁挡住谁；
- 新空间必须重建地理关系。

### Action

- 关键动作至少有可读的起因和结果；
- 若动作会跨镜，必须有共享动作相位。

### Information

- 手机、合同、伤口、门锁、倒计时等必须读清；
- 文字可读性若不是模型强项，考虑后期叠加而非强迫生成。

### Reaction

- 某句台词真正改变关系时，需要听者反应；
- 反应不等于每句台词都切听者。

### Transition

- 人物从坐到站、从屋内到门口、从持枪到失枪等大状态变化，需要看见或明确省略理由。

## 10. Pacing

`held`：让观众停留，适合压力、等待、发现、情绪落点。

`neutral`：正常叙事速度。

`compressed`：信息密度提高，适合追逐、危机、快速升级或短剧高密度段落。

Pacing 决定：

- 平均镜长；
- 是否需要 reaction hold；
- 是否允许更高 cut density；
- 建立镜头应该多快结束；
- 高潮前后是否需要节奏对比。

不要把整集所有镜头都设成同一节奏。

## 11. Cut Motivation Map

正式拆镜前，可先列“必须产生切点”的地方：

| 事件 | 为什么必须切 |
|---|---|
| C01 看向门外 | 下一镜需要 eyeline reveal |
| P01 被翻到背面 | 细节必须独立读清 |
| C02 听到真相后沉默 | 反应承担权力变化 |
| C01 起身冲门 | 动作相位适合 cut on action |

如果某个计划镜头没有任何切点理由，检查它是否能与前后镜合并。

## 12. Missing-Shot Audit

用户说“衔接不上”时，不要只润色 prompt。按下面顺序查：

1. 上一镜结束动作是否完整；
2. 下一镜开始状态是否突然改变；
3. 两镜之间是否缺一个动作阶段；
4. 是否缺 eyeline target；
5. 是否缺建立空间；
6. 是否缺结果/反应；
7. 是否出现未经说明的时间跳跃；
8. 是否为了模型时长把两个 Scene 错塞进同一 Segment。

典型缺镜：

```text
A：角色开始伸手
C：角色已经拿着手机
```

中间可能缺：

```text
B：手触碰手机并拿起
```

不一定必须单独成为一个镜头，但这个动作阶段必须在 A 或 C 中被明确覆盖。

## 13. 30° 与跳切

当连续两个镜头：

- 拍同一主体；
- 时间连续；
- 构图变化很小；
- 相机位置变化不足；

容易产生无意 jump cut。

解决方式：

- 改变机位角度和/或景别；
- 用动作切；
- 插入目标/反应/道具；
- 让 jump cut 成为有意节奏设计并标记。

30°规则是连续性启发式，不是不可违反的法律；重点是不要无意制造视觉跳动。

## 14. Hook Planning

Storyboard 阶段只负责把已有钩子拍出来。

### 强未决型

- 信息缺口；
- 未知威胁；
- 秘密临近暴露；
- 选择未决；
- 认知反转刚落地；
- 倒计时仍在走；
- 行动开始但结果未知。

### 容易误判的“结果型”

- “他被抓了。”然后结束；
- “她赢了。”然后结束；
- “门炸开了。”但没有新的未知；
- 反派身份已经完整揭露且没有新的威胁。

这些可以是高潮结果，但不自动等于下一集钩子。

若原剧本只给结果，不允许在 faithful 模式中凭空补一个秘密电话或新反派。只能准确呈现，并在审计中标记“结果落点，不是未决钩子”。

## 15. Director Plan → Shot

每个 Shot 至少能回答：

```text
它服务哪个 Beat？
它服务哪个 Director Plan obligation？
为什么从这里开始？
为什么在这里切走？
下一镜靠什么接？
```

如果答不出来，镜头可能是冗余镜头，或导演计划还没有收敛。

## 16. 用户已有导演计划时

若上游计划已批准：

- 不重写 `dramatic_job`；
- 不擅自改变 turn；
- 不改变人物关键站位；
- 只在执行层补足镜头；
- 如果发现计划本身导致不可剪/不可生成，单独列出 conflict，并做最小替代方案。

Director Plan 是镜头表的上位约束，不应在分镜阶段被静默覆盖。
